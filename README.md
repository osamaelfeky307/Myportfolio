# Osama Othman — Portfolio

Personal portfolio of Osama Othman, Software Engineer (BSc Computers & AI, Benha University): AI-powered healthcare software, full-stack web, and cross-platform mobile development.

**Live site:** https://portfolio-osos7.vercel.app

## Stack

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS 4
- Framer Motion animations, Lucide icons
- Deployed on Vercel (auto-deploys from `main`)

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Structure

- `lib/data.ts` — all site content (projects, experience, education, skills) lives here
- `components/` — page sections (Hero, About, Experience, Work, Skills, Contact, Footer)
- `app/` — routes and global metadata
- `public/` — photos, logos and CV
